How to Deploy This Project

Pick either the beginner-friendly web method or the quick command-line method.

01

Option A: Deploy via GitHub (Recommended)

  1. Upload or push this project folder to a new repository on GitHub.
  2. Go to vercel.com and sign in with GitHub.
  3. Click "Add New..." → "Project" and select your GitHub repository.
  4. Click "Deploy". Within 20 seconds, your site is live!
02

Option B: Deploy via Vercel CLI (Fastest)

  1. Open your terminal in this directory.
  2. Run npx vercel.
  3. Follow the quick prompts (Log in, accept defaults by pressing Enter).
  4. Your live URL will be generated instantly in your terminal!
